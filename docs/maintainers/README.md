# Maintainer Runbooks

These cover verification and packaging, not first-time product setup.
For an adopter quickstart, see [Self-Hosting](../SELF_HOSTING.md).

- [Verification](VERIFY.md): simulator, service, retry, and deployment checks.
- [Handoff](HANDOFF.md): offline bundles and transferring a development checkout.

Run commands from the repository root. An available check is not a claim that
it passed on every machine; record the environment and actual results with a
change or release.
