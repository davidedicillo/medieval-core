# Security Policy

MediEval is early OSS-first software. Do not use the self-hosted server on a
public network without a token, HTTPS termination, and normal deployment
hardening.

## Supported Versions

Security fixes target the current `main` branch until versioned releases exist.

## Reporting

Report suspected vulnerabilities privately to the project maintainers. Include:

- affected route or component
- reproduction steps
- expected impact
- whether any tokens, labels, or reviewer data may be exposed

Do not include real customer data in reports.
